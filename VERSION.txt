CORRECCIONES PRINCIPALES
1. El LIVE deja de reconectar indefinidamente: máximo 3 reintentos automáticos dentro de una ventana de 90 segundos.
2. Los contadores de reconexión solo se reinician cuando entran bytes RTP reales de audio o vídeo.
3. Errores terminales de permisos, versión, aforo o medios del anfitrión ya no muestran reintentos engañosos.
4. El vídeo LIVE conserva siempre el encuadre completo con object-fit: contain y fondo desenfocado integrado.
5. Sala con cámara sincroniza pausa/reactivación para anfitrión e invitado.
6. Al pausar se muestra avatar, nombre y “Cámara pausada”; nunca pantalla negra.
7. Al reactivar se reutiliza la conexión y se sustituye la pista con replaceTrack/replaceLocalStream.
8. La recuperación automática distingue pausa voluntaria de pista averiada y evita reabrir la cámara indebidamente.
9. LIVE y Sala pueden solicitar credenciales TURN temporales desde un backend Firebase autenticado.
10. Se incluye Cloud Function desplegable y guía de configuración coturn.
