# JEMMO LIVE v2

Estructura base para GitHub Pages.

## Archivos
- `index.html`: portada responsive.
- `live.html`: página temporal de LIVE.
- `familias.html`: página temporal de Familias 24/7.
- `acceso.html`: página temporal de acceso/perfil.
- `assets/jemmo-background.png`: fondo maestro.

## Publicación
Sube el contenido de esta carpeta a la rama `main` del repositorio de GitHub Pages.

La portada usa rutas relativas, por lo que funciona dentro del repositorio `JEMMO-LIVE`.
